Wyckoff watchlist scanner — end-to-end flow

Click any stage to expand its detail. The per-ticker loop expands into five sub-steps of its own.

Scope: this is wyckoff_watchlist_scanner.py — the deep scan of data/core_watchlist.csv (44 names). The separate S&P 500 + AI sweep (wyckoff_scanner.py, driven by data/top50_plus_ai.csv) is a lighter pipeline: only textbook spring/upthrust plus a Weis Wave context flag, no climax/SOS/SOW/LPS/ABC, no charts, no journal drafts, and no explicit bar-count floor. It shares this loop's fetch-level guardrails (rate limiter, retry, unsettled-bar drop) but not the detector or notification stages described below.

Three ways this runs: GitHub Actions cron (split into a daylight-time and standard-time schedule keyed by month, so it doesn't drift an hour off market close for half the year), a manual workflow_dispatch button on GitHub, or running python src/wyckoff_watchlist_scanner.py locally.
  • API key — reads TWELVEDATA_API_KEY env var first (a GitHub secret in CI), falls back to the local gitignored twelvedata_api_key.txt. Fails loudly if neither exists — no silent skip.
  • Ticker list — data/core_watchlist.csv, the 44-name deep-scan list this flow runs against.
  • Guardrail — fetches SPY as the RS benchmark first. If that single fetch fails, the whole scan aborts immediately rather than run partially against a broken benchmark.
Runs once per ticker in the list. Five sub-steps, alternating processing and guardrails:
Twelve Data's free tier caps at 8 credits/minute; a rolling window throttle stays at 7 for headroom, sleeping rather than risking a 429.
Retries twice with a 1s pause on network/timeout errors. On an HTTP 429 it backs off 10s and retries. On a bad symbol or empty response it returns None immediately — no retry, since that's not a transient failure.
drop_unconfirmed_last_bar() discards the newest bar if its volume is under 10% of the trailing 20-day average — a heuristic for "the session hasn't settled yet." Fewer than 60 bars of history and the ticker is skipped outright.
All built on Wilder ATR-14, pivot highs/lows over a 20-left/5-right bar window, and zigzag swings:
  • Textbook spring / upthrust — undercut-and-recover / poke-and-fail, no dilution.
  • Buying/Selling Climax + Automatic Reaction — needs a 2x volume spike and a 1.8x ATR range spike.
  • Sign of Strength / Weakness — 1.5x volume, 1.3x range, closing beyond the level.
  • Last Point of Support / Supply — pullback holding within 0.6x ATR of the broken level.
  • Elliott-style ABC correction — leg-B retrace 30–79% of leg A, leg-C extension 61.8–161.8%.
Every detector is edge-triggered — it fires only the day a condition becomes true, not every day it stays true, so the same alert doesn't repeat for a week. ABC specifically fires only on its exact confirmation day (pivot_idx + RIGHT_BARS), never earlier — the anti-repaint fix for a real lookahead bug found during backtesting, now pinned down by a regression test (tests/test_wyckoff_patterns.py) so it can't silently regress.
If more than half the tickers failed to fetch, that alone triggers a "scan degraded" Telegram message, separate from any signal alert — so a data outage doesn't read as "no signals today." If nothing fired, the scan exits quietly with no notification.
Every alert carries the same disclaimer: "discretionary review triggers, NOT validated edges — backtesting shows none beat naive swing-trading." That's load-bearing, not boilerplate — the backtest confirmed 10 of 11 signal types have a statistically significant negative edge (cluster-bootstrapped, p<0.001). This scanner also generates an annotated chart PNG per signal, uploads it as a 14-day GitHub Actions artifact, and — only on local runs, guarded by a GITHUB_ACTIONS env var check since a CI runner's filesystem disappears when the job ends — auto-drafts a trades.csv row so the signal doesn't need transcribing by hand later.
Guardrails that don't show up as boxes: secrets never touch git (.gitignore covers the key file and trades.csv); there's no fallback data vendor if Twelve Data has an outage (a documented single point of failure, not silently masked); and the entire "review trigger" framing exists because the backtest, not intuition, proved there's no mechanical edge to trust blindly.
